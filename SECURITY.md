# Security Policy

## Responsible Disclosure
As a Cloud Infrastructure Engineer, I take security seriously. If you discover any security misconfigurations or vulnerabilities within my public repositories, please do not open a public issue. 

Instead, please reach out via the secure contact methods listed on my profile. 

## My Security Standards
*   **Zero Credentials:** No secrets, keys, or sensitive state files are ever committed to this repository.
*   **Automated Scanning:** All repository changes are subject to automated security linting and static analysis.
*   **Least Privilege:** All GitHub Actions are configured with restricted `GITHUB_TOKEN` permissions.
